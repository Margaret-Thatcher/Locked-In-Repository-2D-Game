## About the game
Locked In is a top down 2D horror game made in Godot 4.7.

You fell asleep studying and got locked in the library overnight, and your exam is tomorrow morning. Find all 5 books hidden around the dark library and bring them back to the front desk to get out. Ghosts float through the walls and follow you if they see you. If one touches you, it's game over.

### Design goals
- **Objective:** collect 5 books and return them to the front desk
- **Perspective:** top down, the camera follows the player
- **Ending:** win by bringing all 5 books to the front desk, lose if a ghost touches you (jumpscare then game over)
- **Feeling:** tense and creepy. The library is dark, you only see what is near you, and you can hear the ghosts before you see them

### Controls
- WASD or arrow keys to move

### How to run
Open the project in Godot 4.7 and press play. The game starts on the start screen.
